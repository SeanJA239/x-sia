成为 `active` 成员之后,应用里对你开放三块东西:会员卡、AI 权益、资源共享。门面站（也就是你现在在看的这个站点）只负责介绍和文档,这些功能本身都在**应用**里。

## 会员卡

网页卡片是你身份的**主形态**,不是"给安卓用户的兜底方案"。它是独立的全屏路由,配合"添加到主屏幕",打开就是整张卡,能做静态图做不到的事:动效、实时数据、随身份变化的卡面。

卡面上目前有:

- **社员编号**——`26001` 这样的格式,分配后终身不变,详见[加入指南](/docs/join)和[编号设计理念](/blog/why-your-member-no-is-26xxx)。
- **称号（title）**——第一年由干事手工授予,你可以在多个称号里选一个"佩戴"到卡面上,默认显示最新获得的。
- **届别、加入日期、出勤次数**。

Wallet Pass（真正能装进 iPhone 钱包的那种)和实体卡是后续阶段的载体,会和网页卡片共用同一套视觉语言,但网页卡片先上。

## AI 权益

社团用一个 Cloudflare 账号统一代理 AI 请求,你不需要也不会拿到任何 API Key——所有对话都经过应用里的网关。

- 每个 `active` 成员有每日额度,配额档位由权益记录（entitlement）决定,可以被单独提档。
- 「我的权益」页面实时显示额度余量。交了社费,交付感必须看得见。
- 日常对话默认走小模型,大模型限定在特定场景开放。

超出额度会得到明确的提示,而不是静默失败。

## 资源共享

社团积累的资料、模板、往期活动素材都在资源库里,面向 `active` 成员开放下载。

- 上传者信息会被记录,方便追溯归属和处理版权问题。
- 下载走服务端签发的短时效链接,不会把存储直链暴露出去。
- 默认可见范围是"仅会员",这既是一项社费权益,也是维持社团粘性的机制之一——所以保持 `active` 状态很重要。

## 还没开的功能

论坛/墙、活动签到、称号授予的自助界面都在后续迭代中,第一年不作为门面站文档的重点。等这些功能上线,文档会同步更新。
