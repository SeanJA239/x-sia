## 关于这个条目

这是一篇 **本地模块联调示例**，用于检查阅读、搜索、编辑和发布流程，不是从 Notion 导入的正式知识文档。

## 阅读与查找

任何访客都可以阅读已发布条目，无需注册或登录。首页可按分类浏览，也可搜索中文标题、摘要和正文。

> 保存草稿不会改变公众看到的内容。只有明确发布之后，新的版本才会公开。

## 编辑流程

1. 打开「编辑工作台」，使用具有 Wiki 编辑权限的账号登录。
2. 新建条目，输入稳定的英文 Slug，并填写标题和分类。
3. 在编辑器中书写 Markdown，或导入本地 `.md` / `.txt` 文档。
4. 保存草稿，检查预览，再由管理员发布。

## 常见 Markdown

可以使用代码块、列表、表格和链接：

```sh
# 示例命令，不会由 Wiki 自动执行
echo "Hello, X-SIA Wiki"
```

| 操作 | 公众页面是否变化 |
| --- | --- |
| 编辑但未保存 | 不变 |
| 保存草稿 | 不变 |
| 发布已保存草稿 | 更新为新版本 |
| 撤回公开版本 | 条目不再公开可见 |

## 版本与恢复

每次保存都会保留修订。旧版本可载入编辑器，再保存成一个新版本；不会抹掉历史。

如果两个编辑窗口同时修改同一条目，后提交的旧版本会收到冲突提示。请先下载正文备份，再刷新并人工合并。

## 本轮边界

目前只验证本地模块，不连接 Notion，不发布到公网。图片、PDF、批量导入、正式内容整理将在后续迭代中处理。
