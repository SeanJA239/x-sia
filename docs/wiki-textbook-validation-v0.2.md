所有章节、跨章引用、公式、插图、搜索及整卷阅读使用 Wiki 原生 React Router 页面和平台导航，路径保持 `/wiki/`。不是 iframe 或独立站 HTML 的嵌套。

独立书站 8083 已停止后，原生 Wiki 验收通过；生产构建亦打包全部正文、图和字体，不需要 8083、Notion 或运行时读取书站页面。教材源仍统一维护于 `apps/books/content/`，未复制到 D1；社区条目的网页编辑与发布流程没有改变。
