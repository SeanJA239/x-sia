# 决议增补（2026-08-23 拍板，晚于 design.md）

以下决议覆盖 design.md 中的对应未决项：

- **时间线**：一周冲刺。前两天阶段一（schema、登录、admin 确认、个人页），中间三天阶段二（AI 网关、权益页、资源、静态卡片路由），最后两天门面站与联调。活动签到、论坛、title 授予 UI 顺延为周后迭代（schema 照建）。
- **member_no 口径**：级 + 三位序号，整数存储。26 级第 1 位入社 = `26001`。级取首次入社年级（两位年份），按级重置序号，前缀保证全局不重号，约束用 `unique(org_id, member_no)`；跨届续费不换号，终身不变。在 status 首次变为 active 时分配。
- **命名**：社团与平台均为 X-SIA。
- **旧校园论坛平台**：不复用。
- **社员投稿**：双轨制。D1 平台内发帖为默认轨（阶段三）；fumadocs + git PR 为精选轨（门面站 `blog/` 目录 + CONTRIBUTING 规范，第一周即开）。
- **Luma**：仅作对外报名层，`event.luma_id` 为人工关联指针；权益相关出勤只认自家签到。
- **title / cert**：第一年全部手工授予，`rule_json` 留空，不做规则引擎。title 需要「佩戴」概念（成员选一个上卡，默认最新）。
- **发信**：暂缓，注册登录不依赖邮件；email 人工核验（verified_by='manual'）。
- **Apple Developer**：已有账号（Wallet Pass 属阶段四，本周不做）。
- **视觉语言**：正式定稿暂缓，本周使用 LinkCode 式提案基调（见下）。

## 视觉基调（提案，本周执行标准）

参考 linkcode.ai：浅灰纸面、发丝线分区、近单色文字层级、黑色主按钮，颜色只在功能处出现。

- 字体：正文 Geist + Noto Sans SC；数据 / 编号 Geist Mono；品牌字 Archivo 800
- 亮色：纸面 `#F5F5F6`，表面 `#FFFFFF`，描边 `#E2E2E2`，发丝线 `#EFEFEF`，正文 `#161616`，次级 `#757575`，弱化 `#9C9C9C`
- 主按钮：`#171717` 底 + `#FAFAFA` 字，圆角 8px
- 功能色：链接 / 进度 `#2F5EEA`，成功 `#009756`，警示 `#A05C00`，编号金 `#8A6A1E`（浅底 `#F3ECDA`）
- 深色只用于全屏卡片路由：`#121212` 纸面、`#1C1C1C` 表面、`#2C2C2C` 描边；主按钮反转（白底黑字）
- 会员卡卡面：深海军蓝 `#101B33` + 蓝色辐射渐变 + 金色编号 `#E7C877`（三载体统一）
