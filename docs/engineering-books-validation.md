# 工程基础丛书 0.1：交付检查

## 交付范围

本轮制作了五卷基础篇的本地电子书工程，基于 Notion 中的系统、工具链、软硬件协同与数学学习框架重新撰写正文。没有复制私人账号、网络配置、凭据或研究结果。

- 正文：`apps/books/content/`，5 卷 × 4 章，共 20 章。
- 阅读站：`http://localhost:8787/books/`。
- 独立预览：`http://localhost:8083/books/`。
- PDF 下载：`http://localhost:8787/books/downloads.html`。
- 可持续编辑的工程与使用方法：`apps/books/README.md`。
- 私人来源映射：`.local/engineering-books-sources.md`，被 Git 忽略。

这是基础篇编辑草案，不是覆盖全部本科内容的终版。原 Wiki 动态编辑功能仍保留；本轮电子书正文由 Markdown 维护，没有改动 API 或将正文自动发布到 D1。

`pnpm books:test`：**15/15 通过**。

覆盖：

- KaTeX 构建时渲染与 MathML。
- 错误公式中止构建，而非静默保留破损公式。
- 原始 HTML/脚本不透传；远程图片和危险链接协议拒绝。
- 跨章链接、整卷内跳转、唯一章节锚点。
- 全部生成页面的本地链接、片段、图片、样式和脚本存在。
- 中文全文索引及私人 Notion 指针排除。
- SVG 的标题、描述与基本安全结构。
- 选定的确定性算例：umask、BDP、恢复时间、排队、定时器、UART、分页、缓存、Amdahl、最小二乘、Euler、Bayes、融合、RC、卷积与混叠。

这些算例断言不是对全书全部推导的形式证明，也不是硬件或生产性能测试。
