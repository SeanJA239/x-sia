## 软件示例检查

结果：**17 项中 16 项通过、1 项明确跳过、0 失败**。

覆盖：

- 10 个标记 Bash 示例语法；子任务退出码与环境隔离。

- Python 无缓冲描述符的共享偏移与独立 open。
- 发布器完整写入、空输入、前导短横线目标、参数错误、缺失父目录、拒绝覆盖与临时文件清理。
