# 五卷教材原生纳入 Wiki

## 用户要求与实现边界

取消 Wiki 到独立 `/books/` 阅读站的跳转。Wiki 首页直接呈现 Linux、服务器、嵌入式、计算机系统和数学工具的五卷目录、20 章正文索引；阅读时始终使用 Wiki 布局、导航与路径，不使用 iframe、反向代理嵌套页面或独立书站样式。

这次不改后端 API、数据库模型或现有条目的发布权限。教材源文件继续集中维护于 `apps/books/content/`，作为 Wiki 内置课程内容在开发和生产构建中打包；不存在另一份手工复制的正文。现有 D1 社区条目继续支持网页编辑和修订，内置教材不会冒充已有 D1 修订记录。

## Wiki 原生路由

- `/wiki/`：五卷目录、20 章与社区条目的统一搜索入口。
- `/wiki/learn/:volume`：卷目录、先修和学习路径。
- `/wiki/learn/:volume/:chapter`：原生章阅读、公式、插图、章节目录、上下章。
- `/wiki/learn/:volume/print`：Wiki 布局内的整卷阅读与打印。

路径与章标识必须匹配本地书目白名单，否则返回 404。书中 `book:` 跨章引用转成 Wiki 内部导航，`asset:` 引用仅允许已打包的 20 幅技术 SVG。公式使用 KaTeX，字体和图片由 Wiki 自身提供，不依赖 8083 或外部 CDN。

## 搜索和显示

同一关键词和分类筛选用于教材与社区条目。分开显示两类结果数，社区分页仍只作用于社区条目，避免虚构总页数。即使社区 API 不可用，教材仍可读取，页面明确显示社区暂不可用而不是伪称没有条目。

## 编辑与发布边界

用户授权在本地 Wiki 中涵盖教材，不意味着对外部署或修改 Notion。本轮只做本地集成。教材仍为基础篇编辑稿，需要逐章审校；源码编辑与 D1 网页编辑的区别应在阅读页面说明。独立书籍工程保留为源文件与离线/PDF 导出工具，不再作为 Wiki 的外跳入口。

## 验收要求

从 Wiki 首页到任意章及跨章链接不离开 `/wiki/`；20 章正文、数学和图均可在 Wiki 内显示；桌面与手机不整体横向溢出；无 JavaScript 首屏具备正文和数学；停止独立书站后仍可阅读。保留活动页和其他平台入口；验证危险 HTML/远程图片防护及非法课程路径 404。
