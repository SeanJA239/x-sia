# 工程基础丛书：编辑与交付约定

## 目标与边界

依据用户指定的五个方向，重写为有递进结构、推导、插图、例题、练习和参考资料的电子书，而非笔记聚合页。Notion 只提供选题框架；教材正文新写，不嵌入私人页面、附件或账号信息。

首版采用五卷、每卷四章的基础篇。它建立完整的基础学习路径，但不冒充覆盖内核开发、生产运维、全部 MCU 或完整本科数学课程的终版教材。正文状态明确为编辑草案，硬件步骤未实机验证。

## 五卷与先修关系

1. Linux 基础：系统与进程；文件与权限；Shell 与数据流；观察与自动化。
2. 服务器基础：网络与 SSH；服务与 HTTP；存储与恢复；容量与隔离。
3. 嵌入式基础：电路与 GPIO；工具链与启动；时间与中断；通信与调试。
4. 计算机系统：数据与指令；编译链接与 ABI；虚拟内存与缓存；并发与性能。
5. 数学工具：向量与最小二乘；微积分与数值方法；概率与估计；信号与反馈。

读者可先学 Linux，再走服务器或嵌入式路线；系统卷解释底层机制；数学卷按章节提供公式基础。每章显式给出先修、目标、适用条件、例题、练习及解题提示。

## 技术路线

- 新建 `apps/books`，与既有 Wiki 编辑系统并存，不更改 Wiki API 或数据库。
- Markdown 为正文唯一编辑源，JSON 为书目；统一构建静态 HTML。
- 构建时渲染 LaTeX 数学，KaTeX 样式及字体本地随包分发。
- SVG 原创技术图通过脚本生成，可版本化、缩放、打印；每幅图有替代文本和正文解释。
- 不执行 Markdown 中的 HTML、脚本或 MDX；不在构建中执行教材代码。
- 支持卷目录、章目录、上下章、全书检索、整卷打印和离线 HTML。
- `dist/` 为构建产物，不进 Git。页面标明本地编辑预览，不暗示已经公开发布。
- 本地静态服务仅监听 `127.0.0.1:8083`；网关拟增加 `/books/` 转发。Wiki 开发环境提供书籍预览入口，生产构建不显示该入口。

## 内容质量门槛

- 不能只有目录和知识点清单：应解释问题、机制、推导、例题和边界。
- 公式中的符号、单位和假设需解释，避免用公式装饰页面。
- 技术图必须表达关系、结构、时序或数值函数，不以装饰图替代解释。
- 命令注明环境和副作用。默认不提倡 root、全局杀进程、关闭防火墙或删除整个目录。
- 不把应用层指标当硬件性能，不把进程存在当服务成功，不把 Flash 校验当功能验证。
- 新写的确定性算例可用单元断言检查，但不能据此声称硬件、Linux 或生产部署已经验证。
- 每章附公开权威资料；私人来源映射只保留于 `.local/` 编辑记录。

## 验收

自动检查：书目唯一性、正文结构、公式编译、插图存在及替代文本、内部链接、检索索引、安全渲染、确定性算例。浏览器检查桌面与手机阅读、图片/字体、公式、检索、目录、离线无 JavaScript 阅读及打印。

独立技术审校、真实 Linux 命令验证、硬件验证、外部参考链接持续检查、EPUB 与 PDF 文件发行均与静态构建验收分开记录。

图像生成服务本轮因账户地区不支持而失败；改用本地原创 SVG 封面与技术图，不声称生成了 AI 封面。
